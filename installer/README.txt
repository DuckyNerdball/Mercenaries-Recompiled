Mercenaries Recompiled - Cheat-Menu Build (installer)
=====================================================

YOU NEED YOUR OWN COPY OF THE GAME: the original Xbox release of
Mercenaries: Playground of Destruction (USA), as an .iso file.
This package contains NO game code and NO game data. The installer builds the
game on your PC from your own disc, using the public source code at
https://github.com/DuckyNerdball/Mercenaries-Recompiled (branch cheat-menu),
a fork of KraftMacAndChee's Mercenaries Recompiled.

INSTALL
  1. Extract this ZIP anywhere.
  2. Double-click Install.cmd and pick your ISO when asked.
  3. Wait. First install downloads Python 3.12 and Visual Studio 2022 Build
     Tools if you don't have them (several GB), then builds for 20-40 minutes.
  4. Start "Mercenaries (Cheat Build)" from your desktop.

Default install folder: %USERPROFILE%\Games\Mercenaries Cheat Build
Pick another:  Install.cmd -InstallDir "D:\Games\Mercs Cheats"
Update later (keeps saves/settings):  Install.cmd -Update

IN GAME
  F9, or L3 + R3 on a controller ... cheat / developer panel
  Hold LB + click R3, or F7 ......... airstrike at your crosshair
  Hold LB + D-pad left/right ......... choose the airstrike
  Mods "All Supports" (every support item in the shop for $1) and
  "Clear Skies" (half the fog) are generated from your own game files and
  enabled by default; untick them in the mod selector to play without
  (running Install.cmd -Update ticks them again).
  Starts at 1920x1080 borderless; change it in Recomp Options.

Full feature list and test status:
https://github.com/DuckyNerdball/Mercenaries-Recompiled/blob/cheat-menu/docs/CHEAT_MENU.md

TROUBLE
  Everything is logged to install.log in the install folder.
  Report problems: https://github.com/DuckyNerdball/Mercenaries-Recompiled/issues
  Never post your ISO or game files publicly.
